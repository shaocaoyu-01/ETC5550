The residuals don’t appear to be white noise:

The time plot of innovation residuals show several periods of volatility clustering, and the spread of residuals is not constant. For a correctly spcified model the residual variance should be roughly constant in a multiplicative-error model. The ACF plot shows several autocorrelations that poke outside the 95% confidence bounds. Lags 6,10,14,16,24,33 month are significant. The ACF is not the flat, ” all bars inside the bounds” pattern we would expect from white noise. The Ljung-Box test with lag 24 and dof = 17,gives a test statistic of 60.18 with a p-value of 1.39e -10. Since this p-value is far below 0.05, we rejected the null hypothesis that the residuals are white noise.

Robust check: per-folder RMSE

The accuracy() call above pools every forecast from every fold into a single RMSE. As a robustness check we also compute the RMSE within each fold and average across folds, so that each forecast origin contributes equally.

Result of cross-validation

The two tables above give the same information in two ways. The first table shows the RMSE of all four methods under all three evaluation approaches; the second narrows the focus to the one comparison that actually matters, ETS against its strongest rival, the seasonal naive method.

  1. The rank order of the two weakest methods is unchanged. Under every approach, the mean method is clearly the worst and the naive method is second worst. Neither cross-validation nor the test set rescues them, so the conclusion about these two methods is robust.

  2. The gap between the top two methods collapses. This is the only place where the conclusion changes, and the table of ETS-versus-seasonal-naive makes it explicit.

So the size of ETS’s advantage is not a stable quantity. It shrinks from 20.3% on the test set to 3.2% under pooled cross-validation, and becomes slightly negative (-1%) once folds are weighted equally. The same data supports either “ETS is clearly best” or “the two are tied”, depending only on how accuracy is measured.

  1. Fold-to-fold variation is far larger than the difference between the two methods. ETS beats seasonal naive in only 10 of 22 folds, essentially a coin toss. Meanwhile the RMSE varies from 5.9 to 104.4 across folds — a spread an order of magnitude wider than the 0.25 gap between the two methods. This is the clearest evidence that the difference between ETS and seasonal naive is not meaningful.

  2. The ETS model itself is not stable across folds. The automatic selection does not pick the same model each time: it chooses ETS(M,Ad,M) in 16 folds and ETS(M,A,M) in 6 folds. When the “best” model changes just because the training window shifts by a year, the claim that it is the best model is itself fragile.

In conclusion, Yes, cross-validation changes the conclusion. The test set suggests ETS is clearly the best method, but cross-validation shows that ETS and the seasonal naive method are effectively indistinguishable — and on the fold-averaged measure seasonal naive is very slightly ahead. The honest summary is that ETS and seasonal naive perform similarly, and both are clearly better than the mean and naive methods. The strong claim based on the test set alone is therefore not robust.

Question 4

Which method of envaluating is more reliable

I think the time series cross validation is more reliable, for several reasons below:

  1. It averages over many test periods, rather than relying on one.The test set approach produces a single RMSE based on one particular 4-year window. Because forecasts are only accurate relative to the conditions in that window, the result is highly sensitive to the choice of split. Cross-validation here uses 22 different forecast origins, so a single unusual period cannot dominate the answer.

  2. I think the time period is too special. 2019-2022 include the COVID-19 shock and a subsequent strong rebound in retail tunrover, none of the models above take this issue into account. The test set RMSE therefore largerly measure how well a model copied with an unprecedented event, rather than its general forecasting ability. Cross validation spreads the evaluation across ordinary periods as well.

  3. Cross validation uses a longer, more varied evaluation window(1997-2022), and can be designed to match the forecast horizon of interest. We evaluate a 5 year horizon, reflecting how the forecasts would actually be used, and every model was trained only on data available at each origin.

  4. It exposes variability that a single number hides. The per fold plot shows RMSE ranging from about 5.9 to 104.4 depending on the origin.

Cross validation is not perfect. Its folds overlap, for example, successive training sets share data and successive forecast windows overlap in time.

Here, the test set overstates the case for ETS.The test set suggests ETS is substantially better than seasonal naive, cross validation suggests the two are essentially equivalent. Since cross validation averages over many origins and is far less sensitive to the luck of a single split, the cross validation is preferred.
